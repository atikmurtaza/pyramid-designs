# Company prototype

## Page narrative and hierarchy

Phase 1H introduces `/company` as a factual-restraint prototype. It explains Pyramid Designs as a Pakistan-focused multidisciplinary practice, then moves through a provisional working model, broad disciplines, MAD Alpha Designers context and contextual pathways to Work, Culture, Careers and Join.

The route uses a single H1, then H2-led sections in logical DOM order. It deliberately does not add `/about`; the existing navigation label remains **About** and now points to `/company`.

## Multidisciplinary model and discipline taxonomy

The workflow is a semantic ordered list: context and strategy, design, technical development, delivery and refinement. It is illustrative only, not a contractual project process or a claim that every project follows the same sequence.

The provisional taxonomy separates delivery disciplines (Design, Development, Engineering, Marketing and content) from commercial and operating disciplines (Sales, Operations and project functions). Sales and operations are not described as client-facing creative services. The final taxonomy requires owner approval.

## Parent company and Pakistan-market treatment

Pyramid Designs remains the subject of the route. The MAD Alpha Designers section is compact and secondary, using the existing verified external website reference and the already documented company-context wording. It does not claim a precise legal entity relationship.

Pakistan is described only as the market focus. The page makes no city, address, national-coverage, legal-entity, historical, personnel, client, revenue, award or performance claim.

## Synthetic content and media

No new photography is used. The page employs a semantic CSS geometry composition so it does not imply factual people, places or projects. All explanatory copy is provisional and visibly labelled in the hero where production wording needs approval.

## Responsive behavior and accessibility

The desktop workflow is a staggered two-column visual sequence. At 768px and below it remains a two-column sequence without offsets; at 480px and below it becomes one linear column. Hero, discipline groups, parent context and next links collapse to a single logical column on mobile.

The page uses semantic sections, one H1, ordered and unordered lists, meaningful headings and link labels, visible shared focus states and 44px minimum link targets. The workflow has equivalent textual content and does not encode meaning by colour alone. Existing reduced-motion, forced-colours and contrast foundations apply. There is no automatic motion.

## Performance, metadata and production replacement requirements

The route is a server component with no Company-specific client component, dependency, remote image, CMS, database, API, analytics, authentication, 3D or WebGL. Its metadata uses provisional-safe title and description. No Organization structured data is emitted.

Before production publication, approve and replace the company legal name, exact parent-company wording, operating location and contact channels, final service and discipline taxonomy, approved capabilities and examples, approved Pakistan-market copy, legal review ownership, and verified Organization structured-data fields. Structured data must be added only after those details are verified.
